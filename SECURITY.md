# Security

If you find a security problem in De-ID Desktop, such as a way it could
send data out, leave an identifier in a clean copy it says is checked, or
expose the crosswalk that maps clean copies back to real names, please
report it privately rather than in a public issue.

- **On GitHub:** use [Report a vulnerability](https://github.com/hantswilliams/de-id-desktop/security/advisories/new)
  on this repository's Security tab.
- **By email:** [hello@deid-tool.com](mailto:hello@deid-tool.com?subject=De-ID%20security),
  with "De-ID security" in the subject.

Please don't include real identifiers. Describe the problem with made-up
data, and say which version and system you used.

You'll get a reply within a week. De-ID is made by one person, so a fix may
take longer; you'll hear what's planned and when.

Only the latest release is supported. The [security review](https://deid-tool.com/security.html)
says what De-ID stores, what it connects to, and what it can't promise.
